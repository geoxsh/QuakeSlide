# Demo

The global datasets used by QuakeSlide are too large to include in this repository. For demonstration purposes, we prepared a small set of cropped input data for the **5 August 2018 Mw 6.9 Lombok earthquake** (USGS event ID: `us1000g3ub`).

The demo input data are provided in `demo/data/`. To run the demo, open `QuakeSlide.ipynb` from the project root and run **Section 4: Demo**.

The outputs will be saved in:

```text
Results/us1000g3ub/
```

The model files in `Model/` and the Python and R dependencies listed in the main `README.md` are still required.
